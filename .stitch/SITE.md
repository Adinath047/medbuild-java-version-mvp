# Medicos EMR — Google Stitch Project Configuration

## Site Vision
Medicos EMR is a modern, full-stack Hospital EMR & Patient Management System built with Spring Boot Java 24 backend and React/TypeScript frontend.

## Stitch Project Details
- **Project ID**: `medicos-emr-v1`
- **Engine**: Gemini 2.5 Flash (Google Stitch AI UI Generator)
- **Target Platform**: Desktop & Tablet Responsive Medical EMR
- **Design Token Theme**: Modern Clean Healthcare (#0f766e teal primary, sleek dark/light modes, zero emojis, pure SVG vector icons)

## Sitemap
1. `doctor-dashboard`: Daily appointments, quick patient intake, queue status
2. `bed-allocation`: Wards, ICU/General/Emergency bed occupancy, vital signs monitoring
3. `prescription-writer`: SOAP notes, dosage calculator, print slip preview
4. `patient-detail`: Patient EMR timeline, vitals, history, labs, uploaded documents
5. `billing-pharmacy`: Pharmacy billing, OPD/IPD invoices, payment tracking
